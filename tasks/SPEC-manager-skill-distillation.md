# 衡策基金经理决策蒸馏规格

## 1. 目标

把 Augur、InvestorSkills 与 AI Berkshire 中与衡策 Quant Desk 现有能力兼容的投资研究方法，蒸馏为一套统一、可审计、可执行的基金经理契约。用户切换基金经理后，平台必须在同一组事实数据上改变关注因子、硬门槛、评判流程、仓位与复核节奏，同时明确哪些结论因证据缺失而不能生成。

这里的“蒸馏”指多源方法论与工作流蒸馏，不是机器学习模型蒸馏，也不表示复刻投资人物本人。

## 2. 产品边界

- 保留现有基金经理选择器、个股分析弹窗与持仓评价，不新增一级页面。
- 基金经理面板承载：投资范围、决策节奏、因子权重、硬门槛、证据政策与五步流程。
- 个股分析承载：事实数据、财报与增长、公司新闻、经理解读；同一事实不因经理切换而改变。
- 持仓评价承载：论文健康度、红线、证据等级、复核节奏、集中度与机会成本提示。
- 缺失数据必须显示“待补证/无法判断”，不得用中性分或生成式文字补齐。
- 公开人物仅作为公开资料方法论映射，不声称代表本人观点、实时持仓或投资建议。

## 3. 三源蒸馏映射

### Augur → 差异与挑战

- 每位经理有独立因子权重与决策阈值。
- 展示因子贡献，而不只展示一个总分。
- 在最终结论前保留反方检查与分歧，避免单一路径确认偏误。
- 仓位必须受置信度与风险预算约束；当前产品不直接照搬 Kelly 百分比。

### InvestorSkills → 统一契约骨架

- 世界观与投资范围。
- 时间范围与决策节奏。
- 信号、硬过滤、分析步骤、仓位、风险、执行、监控与来源。
- 结构化参数为规范值，说明文字解释如何使用。

### AI Berkshire → 证据纪律与持仓复核

- 信息丰富度 A/B/C 与“资料少不等于通过/不通过”。
- 决策关键财务字段优先一手来源，并要求两个独立来源；相对差异超过 1% 时触发冲突闸门。
- 强制区分通过、否决、灰色地带与待补证。
- 记录 3–7 条核心论文假设、红线与复核时间；论文健康度按公开规则计算但不得伪造假设状态。
- 组合评价包含集中度、相关风险、机会成本与压力场景；没有相关性数据时只给结构提示。

## 4. 统一基金经理契约

每位经理必须具有：

- `methodologyVersion`
- `decisionCadence`
- `universe`：资产类别、市场、排除项、最低数据要求
- `factorBias` 与可归一化后的五层权重
- `requiredCapabilities` 与 `hardGateCapabilities`
- `decisionProcess`：筛选 → 研究 → 反方挑战 → 决策 → 监控
- `evidencePolicy`：一手来源要求、独立来源数、1% 冲突阈值、缺失数据动作
- `sizingPolicy`：首笔区间、单笔风险、经理暴露上限/下限
- `monitoringPolicy`：复核节奏、论文假设范围、失效规则
- `sources`：人物公开方法论来源与三套蒸馏来源分开记录

## 5. 可执行规则

### 5.1 证据等级

- A：关键事实有一手来源，且至少两个独立来源完成核验，无超过 1% 的未解释冲突。
- B：有可用来源，但缺一手来源或缺双源核验；结论只能是条件性结论。
- C：关键事实不足；结论必须是待补证/无法判断。
- `conflict`：任一关键双源字段相对差异 > 1%；买入结论必须降级为等待，直到冲突被解释或修正。

### 5.2 研究流程

1. 筛选：确认投资范围与硬门槛。
2. 研究：采集经理所需事实与来源。
3. 反方挑战：记录最强反例、失败情景或趋势反转条件。
4. 决策：输出买入、持有、等待、减仓之一，并附证据等级。
5. 监控：记录论文假设、红线和下一次复核节奏。

### 5.3 论文健康度

仅在用户或数据源提供了假设状态后计算：

`health = clamp(10 - broken*3 - damaged*2 - weakened - redLines*5, 1, 10)`

若没有结构化假设，显示“尚未建立论文基线”，不得默认 10 分。

### 5.4 财务冲突

对两个非零数值使用对称相对差异：

`abs(a-b) / max(abs(a), abs(b))`

差异大于 0.01 时标记冲突；缺少任一来源时标记未核验而不是冲突。

## 6. 验收标准

- 所有经理都通过统一契约校验，且保留真实差异。
- 相同基线权重切换经理后，因子贡献可解释并归一化到 100%。
- 缺关键证据或存在 >1% 冲突时，买入动作被硬门槛降级。
- 论文健康度公式有单元测试；无基线时不生成虚假分数。
- 个股分析出现 4 个可访问标签页，财报/新闻数据动态加载，失败不影响行情页。
- 产品介绍与简历准确描述“可切换投资经理 + 三源方法论/工作流蒸馏 + 证据闸门”。
- 聚焦测试、完整测试与生产构建通过；浏览器验证桌面与窄屏布局。
