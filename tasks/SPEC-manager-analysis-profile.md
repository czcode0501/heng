# 经理分析档案与行情来源优先级

## 目标

让每个自建组合同时拥有一位基金经理、目标年化回报和风险承担能力。这三项组成唯一的“分析档案”，所有需要判断的得分、目标仓位、股票建议和持仓评价都必须使用该档案。

## 能力地图

1. 组合偏好
   - `managerId`：已有经理选择。
   - `targetReturn`：0–100，按年化百分比解释，默认 12。
   - `riskCapacity`：0–100，表示组合可承受的风险预算，默认 50。
   - 数值保存在当前组合，切换组合时各自恢复。
2. 观察标的
   - 每位经理分别输出 A 股和美股方法论观察池。
   - 必须显式标注为研究观察，不暗示本人真实持仓或推荐。
3. 分析变换
   - 原始事实数据（价格、成交量、CPI、利率、日期等）不变。
   - 主观分数保留 `rawScore`，展示值按经理因子灵敏度、风险承担能力和目标回报门槛调整。
   - 搜索股票、宏观/择时/板块/情绪/资金信号、目标仓位和持仓建议共用同一分析档案。
4. IBKR 行情优先级
   - 已连接 IBKR 时，对 IBKR 快照中能匹配的美股持仓，优先使用券商 `marketPrice`。
   - 必须显示来源和数据类型；无匹配、无有效价格或未连接时回退到 yfinance 行情。
   - 未获得 IBKR 行情订阅不得标记为实时；账户窗口估值与任意标的实时行情要分开披露。

## 验收标准

- 两个滚轮都支持键盘，范围 0–100，实时显示数值，位于经理选择器之前。
- 相同行情输入在不同经理或不同风险/回报设定下，得分、仓位或建议至少一项产生可观测差异。
- 对任意宏观样本执行变换后，CPI 及日期与输入完全相同。
- A 股与美股观察池同时可见。
- IBKR 优先报价只在可验证匹配时生效，且回退路径有自动化测试。
