# Implementation Plan: 中美全市场分层扫描器

## Overview

把仅含37个手工标的的验证脚本升级为可重复运行的全市场扫描流程。股票宇宙由官方/零配置来源动态生成；第一层用批量日线和低成本指标缩小范围，第二层只对入围标的运行现有VRVP与五层决策，避免对数千只股票逐只调用完整分析接口。

## Architecture Decisions

- A股宇宙使用 BaoStock 全部上市股票基础资料；美股使用 Nasdaq Trader 的 `nasdaqlisted.txt` 与 `otherlisted.txt`。
- “全市场”指来源当日可识别的正常上市普通股票；ETF、测试证券、权证、单位、优先股、已退市与明显非普通股产品在股票池层过滤。
- 第一层批量初筛仅计算流动性、趋势、动量、量能与距阶段高点，保存断点；第二层按初筛分数选出有限候选，再复用现有 `/api/analysis` 与五层决策模型。
- 运行结果必须披露宇宙总数、成功/失败数、筛选阈值、数据时间和失败原因；不把缺失数据填成中性分。
- 默认使用受控批次、磁盘缓存与断点续扫；支持 `--max-symbols` 做快速验证，但默认不再是固定37只。

## Risks and Mitigations

| Risk | Impact | Mitigation |
|---|---|---|
| 免费源对数千标的限流 | 高 | 分层、批次、缓存、断点续扫；深度分析只跑短名单 |
| 普通股与结构化产品混杂 | 中 | 使用官方字段并增加名称排除规则，输出过滤统计 |
| 个别股票无历史数据 | 中 | 单只失败不终止批次，明确记录失败原因 |
| A股行业映射不完整 | 中 | BaoStock行业关键词映射到统一11行业；未映射时明确为待识别 |
| 全量首次运行耗时较长 | 高 | 支持进度文件和恢复；验证阶段用确定性的限量实跑 |
