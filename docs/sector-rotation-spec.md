# 板块轮动系统规格（中国股票 + 美国股票）

状态：待用户审核后实施  
版本：1.0  
日期：2026-08-14

## 1. 目标

建立一套面向个人投资者的双市场板块轮动系统。系统不自动下单，而是用自动更新的数据回答四个问题：

1. 中国与美国市场当前分别适合投入多少风险仓位？
2. 哪些一级板块正在领先、转强、过热、转弱或落后？
3. 为什么模型得出这个结论，证据是否完整、数据是否新鲜？
4. 使用者应当观察、增配、持有、减配还是退出，并将多少板块轮动资金分配给它？

系统必须把中国和美国独立计算、独立展示，不直接用两国的原始涨跌幅互相排名。

## 2. 已确认的产品方向

- 默认采用中短期、多周期轮动：1周、1个月、3个月、6个月共同参与评分，每周重新评估。
- 输出板块排名、轮动阶段、操作建议和建议仓位。
- 页面采用“一级板块总览 → 点击进入二级行业”的结构。
- 定位为研究与配置建议，不进行自动交易。
- 开源用户默认零配置可运行；任何需要密钥的增强数据都只能是可选项。

## 3. 双市场板块池

中美均使用11个一级经济板块，便于页面理解与跨市场观察，但每个市场只在自己的基准内部评分。

| 统一板块 | 中国分类 | 美国分类/观察ETF |
| --- | --- | --- |
| 能源 | 中证能源 | Energy / XLE |
| 原材料 | 中证原材料 | Materials / XLB |
| 工业 | 中证工业 | Industrials / XLI |
| 可选消费 | 中证可选消费 | Consumer Discretionary / XLY |
| 主要消费 | 中证主要消费 | Consumer Staples / XLP |
| 医药卫生 | 中证医药卫生 | Health Care / XLV |
| 金融 | 中证金融 | Financials / XLF |
| 信息技术 | 中证信息技术 | Information Technology / XLK |
| 通信服务 | 中证通信服务 | Communication Services / XLC |
| 公用事业 | 中证公用事业 | Utilities / XLU |
| 房地产 | 中证房地产 | Real Estate / XLRE |

中国基准默认使用沪深300；美国基准默认使用标普500。二级行业不参与首页横向排名，进入详情后再展示，例如信息技术下钻至半导体、软件、硬件。

## 4. 模型计算流程

```text
行情与成分数据
    ↓
数据质量检查与交易日对齐
    ↓
六维板块评分（0–100）
    ↓
阶段识别 + 排名变化
    ↓
市场择时限制最大风险仓位
    ↓
合格板块筛选与权重分配
    ↓
操作建议 + 证据 + 风险提示
```

### 4.1 六维综合评分

| 维度 | 权重 | 衡量内容 |
| --- | ---: | --- |
| 相对动量 | 35% | 板块相对本国基准在5、20、60、120个交易日的超额收益 |
| 趋势质量 | 25% | 价格相对MA20/MA60/MA120的位置、均线斜率和趋势连续性 |
| 市场宽度 | 15% | 成分股站上MA20/MA60比例、上涨家数占比、新高与新低结构 |
| 资金参与 | 10% | 成交额变化、量比、上涨是否得到参与度确认；ETF资金流仅作增强项 |
| 风险效率 | 10% | 波动率、最大回撤、下行波动以及单位风险收益 |
| 宏观适配 | 5% | 当前宏观阶段是否有利于该板块，只作为轻量加减分，避免重复计算 |

每个原始指标先在“同一国家、同一日期的11个板块”中转换为0–100分位分数，再按权重合成，避免中国和美国不同波动水平造成失真。

相对动量内部权重：

```text
5日超额收益 × 10%
20日超额收益 × 35%
60日超额收益 × 35%
120日超额收益 × 20%
```

最新综合分数保留一位小数，并同时保存一周前分数与排名，用于判断轮动方向，而不是只看当前静态排名。

### 4.2 数据缺失与评分可信度

- 不允许用0替代缺失指标。
- 某个维度缺失时，只在剩余可用维度中按比例重新归一化。
- 相对动量或趋势质量任一缺失时，该板块不得产生“增配”建议。
- 数据可信度低于70分时，只能显示“数据不足/观察”，不得给出建议仓位。
- 页面必须显示数据来源、数据日期、可用维度数量和降级原因。

可信度参考：价格历史完整度35%、成分宽度覆盖25%、数据新鲜度25%、多源一致性15%。

## 5. 板块轮动阶段

| 阶段 | 主要条件 | 默认动作 |
| --- | --- | --- |
| 领先 | 综合分≥70、趋势分≥60、连续两周改善 | 增配/持有 |
| 强势延续 | 综合分≥70、仍在前四但增速放缓 | 持有，禁止追高式加仓 |
| 过热 | 综合分高但短期偏离MA20过大或动量明显减速 | 持有/分批减配 |
| 转弱 | 综合分跌破60或连续两周下降且宽度恶化 | 减配 |
| 落后 | 综合分<40且价格低于MA60 | 退出/回避 |
| 修复 | 综合分尚未达60，但连续两周改善且宽度回升 | 进入观察名单 |
| 中性 | 不满足以上条件 | 观察 |

阶段必须由规则产生；模型同时显示“本周阶段”和“上周阶段”，形成可读的状态迁移，例如“修复 → 领先”。

## 6. 市场择时与仓位算法

板块轮动分数回答“买什么”，市场择时模块回答“最多买多少”。两者不得混成一个分数。

| 本国市场择时状态 | 板块轮动资金最高投入比例 |
| --- | ---: |
| 强势/进攻 | 80% |
| 偏多 | 60% |
| 中性 | 40% |
| 偏空 | 20% |
| 风险关闭 | 0% |

资格条件：综合分≥60、趋势分≥55、可信度≥70。合格板块最多5个，默认选择排名前3；单一板块最高30%，最低有效建议仓位5%。

合格板块的初始权重按下式分配：

```text
有效强度 = max(综合分 - 50, 0)
板块基础权重 = 有效强度 / 所有入选板块有效强度之和
目标仓位 = 基础权重 × 本国市场最高投入比例
```

然后应用单板块30%上限，并将剩余部分保留为现金。建议仓位表示“板块轮动策略篮子中的目标仓位”，不代表用户整个投资账户的强制仓位。

为了降低换手，只有目标仓位变化达到5个百分点，或者阶段发生关键迁移时，才生成调仓动作。

## 7. 原“三探测器”如何保留

三探测器不再决定全部板块配置，而是成为中国市场的解释与确认层：

- 券商：金融板块的流动性与市场β确认。
- 半导体：信息技术板块的成长主线确认。
- 创新药：医药卫生板块对美债利率的敏感性确认。
- IBIT：全球风险偏好的辅助证据，不直接产生中国板块仓位。

探测器与六维评分冲突时，页面必须明确显示冲突。例如“信息技术排名第2，但半导体主线尚未确认”，而不是隐藏不一致。

## 8. 页面信息架构

### 8.1 顶部控制区

- 数据状态：最后刷新时间、最旧数据日期、可信度和降级来源。
- 模型说明：默认“均衡轮动（1周+1月+3月+6月）”。
- 图表观察范围：1月、3月、6月、1年、自定义。该范围只控制走势图；综合评分始终使用固定多周期窗口，防止使用者误解。
- 点击“板块轮动”导航时自动重新检查数据，同时保留手动刷新入口。

### 8.2 双市场结论区

中国股票与美国股票各自一张总结卡，显示：

- 当前市场环境与最高投入比例。
- 当前领涨板块、修复板块和转弱板块。
- 模型建议：进攻、均衡、谨慎或防守。
- 一句话解释本周最重要的轮动变化。

### 8.3 轮动地图

每个国家独立一张四象限图：

- 横轴：相对强度。
- 纵轴：相对强度的变化速度。
- 气泡大小：成交额/板块规模。
- 轨迹：最近4周位置变化。
- 四象限：领先、转弱、落后、修复。

鼠标悬停显示日期、综合分、相对收益和排名；键盘可逐期移动。

### 8.4 板块排名表

每个国家展示11个一级板块：

```text
排名 | 排名变化 | 板块 | 综合分 | 相对收益 | 趋势 | 宽度 | 风险 | 阶段 | 建议动作 | 目标仓位
```

支持按综合分、排名变化、1个月超额收益、风险和建议仓位排序。颜色不能成为唯一信息载体，必须同时显示文字、箭头或阶段标签。

### 8.5 板块详情抽屉

点击任一板块后展示：

- 板块价格与本国基准的归一化对比曲线。
- 六维评分雷达/条形分解。
- 1周、1月、3月、6月相对收益。
- 成分股宽度与领先/拖累个股。
- 最近8周排名和阶段变化。
- 宏观适配证据、风险提示和可交易ETF映射。
- 中国市场相关的三探测器验证结果。

## 9. 数据与接口设计

### 9.1 数据源策略

- 中国：优先获取中证一级行业指数或可稳定映射的公开行业指数行情；成分与宽度数据使用公开成分列表计算。
- 美国：11只Select Sector SPDR ETF作为可交易行情代理；基准使用SPY或标普500公开行情。
- 上游复用现有宏观与市场择时接口，不重复抓取同一数据。
- 主数据源失败时切换备用源；全部失败时读取最后一次成功缓存，并明确标记“缓存数据”。
- 付费或需要密钥的数据源可以后续作为增强插件，但不能成为默认运行条件。

美国11只Select Sector SPDR ETF由发行方公开对应全部11个GICS板块；中证2025版行业分类同样包含11个一级行业，因此两边可以使用一致的一级展示结构。

### 9.2 API契约草案

```http
GET /api/sector-rotation?market=all&profile=balanced&refresh=0
```

响应核心结构：

```json
{
  "generatedAt": "ISO-8601",
  "profile": "balanced",
  "markets": [
    {
      "id": "china",
      "benchmark": {},
      "timing": { "regime": "neutral", "maxExposure": 40 },
      "summary": {},
      "sectors": [
        {
          "id": "information-technology",
          "rank": 1,
          "rankChange": 2,
          "score": 78.4,
          "confidence": 92,
          "phase": "leading",
          "action": "increase",
          "targetWeight": 20,
          "dimensions": {},
          "history": [],
          "evidence": [],
          "sources": []
        }
      ]
    }
  ]
}
```

刷新频率：页面打开时检查；交易时段最多每15分钟更新缓存，收盘后执行完整日线与宽度计算。不同市场使用自己的交易日和时区，响应中分别记录`asOf`。

## 10. MVP边界

### 本期实现

- 中美各11个一级板块。
- 六维评分、阶段、排名变化、动作与建议仓位。
- 双市场结论卡、轮动地图、排名表和一级板块详情。
- 1月/3月/6月/1年/自定义观察范围。
- 自动刷新、缓存、来源显示、降级与可信度。
- 中国三探测器作为辅助证据。

### 本期不做

- 自动下单与券商账户连接。
- 盘中分钟级高频轮动。
- AI自由生成仓位；仓位必须来自可审计规则。
- 默认依赖付费API、用户密钥或登录Cookie。
- 把中美板块放在同一张原始收益榜直接比较。
- 一开始覆盖所有三级、四级概念题材。

## 11. 测试策略与验收标准

### 自动化测试

- Python单元测试：收益窗口、交易日对齐、六维评分、缺失值重权、阶段迁移、仓位上限和缓存回退。
- JavaScript单元测试：双市场渲染、筛选排序、时间范围、详情抽屉和交互图表定位。
- API契约测试：字段、日期、来源、可信度和错误状态。
- 浏览器测试：桌面/移动布局、鼠标悬停、键盘访问、刷新与失败降级。

### 成功标准

1. 中国和美国各展示11个一级板块，且不会跨市场混排。
2. 每个综合分都能展开查看原始证据和数据日期。
3. 同一输入必定产生相同阶段、动作和仓位。
4. 市场风险关闭时，板块仓位总和必须为0。
5. 任一板块建议仓位不超过30%，总仓位不超过市场择时上限。
6. 关键数据缺失或可信度不足时不会生成虚假买入建议。
7. 图表悬停能显示精确日期、数值和排名，键盘也可操作。
8. 无API密钥的全新安装可以获得默认数据或明确的缓存/失败说明。
9. 全部测试、生产构建和依赖安全检查通过。

## 13. 工程边界

- 始终：来源透明、缺失值诚实、先写测试、验证构建、保留最后成功缓存。
- 实施前询问：引入新依赖、改变现有宏观/择时接口、增加付费数据源。
- 永不：硬编码“实时”行情、提交密钥、用未来数据计算历史信号、把回测收益当成实盘承诺。

## 14. 需要用户最终审核的决策

- 是否接受六维评分权重：35/25/15/10/10/5。
- 是否接受市场择时仓位上限：80/60/40/20/0。
- 是否接受单板块30%上限、默认持有前三名、5个百分点调仓阈值。
- 是否批准按本规格进入实施阶段。
