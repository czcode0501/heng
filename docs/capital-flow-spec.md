# 资金流向与板块轮动融合规范

状态：实施中  
来源参考：[`czcode0501/sector-flow`](https://github.com/czcode0501/sector-flow)  
模型版本：`capital-flow-v1`

## 1. 目标

把旧项目中“9 个指标 × 1/5/20 个交易日”的资金压力分析移植到衡策，并扩展为中国股票与美国股票两个独立市场。资金流向仍是可单独阅读、可下钻的证据页面；板块轮动只消费一个去重后的资金确认分。

## 2. 旧项目中保留的分析方法

每个板块代理保留以下九项指标：

1. 涨跌幅：N 日价格变化。
2. CMF：成交量在当日高低区间中的方向位置。
3. Net Flow：`MFM × Volume × TypicalPrice` 的累计值。
4. Flow %：Net Flow 除以同期总成交金额，用于跨板块比较。
5. Up/Down Volume：上涨日成交量与下跌日成交量之比。
6. RVOL：最新成交量相对之前 N 日均量。
7. Close Location：收盘价处于当日区间的位置。
8. MFI：成交金额加权的资金流量强弱。
9. OBV Δ%：能量潮在 N 日窗口内的变化。

时间窗口保持为 1D、5D、20D。数学上无意义的组合必须返回空值，不得补造数字。

## 3. 必须修正的表述

OHLCV 无法识别真实买方和卖方身份。CMF、Net Flow、Flow %、MFI 和 OBV 都是价格与成交量推导出的“资金压力代理”，不是交易所逐笔订单流，也不是机构真实净买入。

界面统一使用：

- “估算净方向成交额”，不使用“机构净流入”。
- “资金压力”，不使用“真实资金去向”。
- 显示来源、时间频率、最新交易日和置信度。

## 4. 页面与模型是否合并

结论：页面分开，数据层共享，模型层有限融合。

### 4.1 页面分开

- 资金流向回答：钱的压力方向、强度、持续性和价格背离是什么？
- 板块轮动回答：在市场择时约束下，哪些板块更值得配置？

两个问题不同，合成一个页面会让原始证据与最终建议混在一起，也不利于发现模型判断错误。

### 4.2 数据层共享

两个模块必须读取同一份板块 OHLCV、同一个板块目录、同一交易日和同一缓存，不重复请求数据源。资金流计算结果作为板块对象的附加字段输出。

### 4.3 模型层有限融合

资金流模型只向板块轮动提供一个 `capitalFlow` 确认分和一个背离状态，禁止将 CMF、Flow %、MFI、OBV 等原始指标逐项再次加入轮动总分。

原因：

- CMF 与 Flow % 使用几乎相同的 MFM 核心公式，高度共线。
- MFI、OBV、Up/Down Volume 都包含成交量信息。
- 当前轮动模型的成交参与维度也来自成交量。

若全部重复计权，同一份成交量信息会在总分中出现多次，造成伪精确和过度自信。

## 5. 资金确认分

`capitalFlowScore` 取值 0–100，由五组互斥含义组成：

| 组别 | 权重 | 输入 |
|---|---:|---|
| 方向压力 | 35% | CMF 与 Flow % 先合并，再按 1/5/20 日加权 |
| 持续性 | 20% | 三个窗口方向是否一致，长期窗口权重更高 |
| 成交参与 | 20% | Up/Down Volume 与 OBV Δ% |
| 价格位置确认 | 15% | Close Location 与 MFI |
| 强度 | 10% | RVOL 只放大已有方向，不独立判定流入或流出 |

窗口权重：1D 20%、5D 35%、20D 45%。这样降低单日噪声，同时保留转折敏感度。

所有输入必须截断到合理范围，空值不参与计算并降低置信度。绝对 Net Flow 只用于展示规模，不直接进入跨板块得分；跨板块比较使用 Flow %，防止大板块天然占优。

## 6. 价格与资金的四象限

以 20D 价格变化和资金确认分组合：

| 价格 | 资金 | 状态 | 解释 |
|---|---|---|---|
| 上涨 | 流入 | 趋势确认 | 价格与资金同向 |
| 下跌/横盘 | 流入 | 潜在吸筹 | 资金先于价格改善 |
| 上涨 | 流出 | 潜在派发 | 价格尚强但资金转弱 |
| 下跌 | 流出 | 趋势确认流出 | 价格与资金共同走弱 |

临界区域标记为“混合”，不得强行输出方向。

## 7. 板块轮动的权重调整

旧轮动权重：

- 相对动量 35
- 趋势质量 25
- 市场宽度 15
- 成交参与 10
- 风险效率 10
- 宏观适配 5

融合后：

- 相对动量 30
- 趋势质量 25
- 市场宽度 15
- 资金确认 15
- 风险效率 10
- 宏观适配 5

`capitalFlow` 替换原来的 `participation`，而不是额外新增第七项。这样总权重仍为 100，并避免成交量重复计权。

`GET /api/capital-flow`

```json
{
  "data": {
    "generatedAt": "ISO-8601",
    "methodologyVersion": "capital-flow-v1",
    "markets": [
      {
        "id": "china",
        "status": "live|stale|error",
        "asOf": "YYYY-MM-DD",
        "summary": {
          "stance": "流入占优|中性分化|流出占优",
          "averageScore": 0,
          "inflowCount": 0,
          "outflowCount": 0
        },
        "sectors": [
          {
            "id": "information-technology",
            "score": 0,
            "confidence": 0,
            "state": { "id": "accumulation", "label": "潜在吸筹" },
            "metrics": {
              "cmf": { "1": null, "5": null, "20": null }

```

接口复用板块轮动缓存。第三方数据异常时返回 stale 或 error 状态，不返回演示数字。

## 9. 页面结构

1. 页面标题、数据质量、刷新按钮。
2. 方法说明：明确“资金压力代理”边界。
3. 中美市场摘要：平均确认分、流入/流出数量、最强流入、最大背离。
4. 板块资金流排名：默认按确认分排序，可切换 1D/5D/20D 观察窗口。
5. 单板块下钻：
   - 价格—资金四象限状态；
   - 九指标 × 三窗口矩阵；
   - 资金压力走势图与精确日期悬停；
   - 数据来源、代理标的和置信度。
6. 与板块轮动连接：提供“查看轮动排名”链接，并解释资金确认在轮动总分中的 15% 权重。

旧项目的红绿整卡底色不直接复制。衡策继续使用现代简洁 SaaS 视觉，只在状态标签、数值和小面积边缘上使用方向色，同时用“流入/流出/混合”等文字避免只依赖颜色。

## 10. 后续成分股层

旧项目的板块详情还包含市值 Top 10、极端资金流 Top 10 和最大涨跌 Top 10。该层应通过懒加载接口独立实现，避免首页一次请求数百只股票：

`GET /api/capital-flow/sectors/{marketId}/{sectorId}/constituents`

首版先完成 22 个板块的一致模型和下钻；成分股层在确认中国市场的免费成分股目录稳定后接入。美国可沿用旧仓库列表，中国必须使用可更新的正式板块成分定义，不应手写长期不更新的股票池。
