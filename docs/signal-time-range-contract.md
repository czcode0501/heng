# 模型信号统一时间范围契约

状态：已实施  
适用范围：宏观信号、市场择时、板块轮动、资金流向，以及后续所有包含时间范围选择的模型页面。

## 固定选项

所有页面必须按以下顺序提供同一组选择：

1. `1d`：1日
2. `1w`：1周
3. `1m`：1月
4. `3m`：3月
5. `1y`：1年
6. `custom`：自定义起点

禁止在单个页面自行改成 5日、20日、6个月、2年或5年等另一套交互选项。模型内部可以保留自己的固定计算窗口，但必须明确标注为“模型证据窗口”，不得与用户选择的观察区间混为一谈。

## 比较语义

- 结束点始终为数据源最新可用日期，不把自然日“今天”伪装成交易日。
- 起点为目标日期当天或之后的第一个有效观察值。
- `1日` 使用最近两个有效观察值，表示最近一期变化。
- 自定义起点不得晚于当前日期。
- 切换范围后，图表、区间变化、高低值、历史分位和观察值数量必须一起更新。
- 月度或季度指标在短窗口内没有日频数据时，使用最近两次发布值并明确说明频率，不插值、不补造数据。

## 实现边界

- 前端唯一目录：`signals/time-range.js`。
- 后端唯一校验：`time_ranges.py`。
- 新页面必须复用这两个模块，不得复制按钮数组或重新编写日期算法。
