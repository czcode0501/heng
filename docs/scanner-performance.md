# 全市场扫描性能记录

## 2026-08-15 基线

- 旧脚本：固定37只股票，直接运行37次深度分析；热缓存下约4.8秒，但没有全市场覆盖能力。
- 官方股票宇宙发现：美股5,320只，A股5,208只。
- 如果把10,528只股票全部逐只运行完整搜索、VRVP与五层决策，冷请求会形成明显的N+1瓶颈，且容易触发免费源限流。

## 保留的方案

- 第一层按批次下载日线，并通过流动性、趋势、动量、量能和位置筛到每市场最多80只。
- 第二层默认只深度分析每市场前40只；深度请求上界从10,528只降为80只。
- 6只/市场的真实初筛验证：美股日线阶段1.42秒，A股日线阶段2.48秒，12只均成功读取、10只通过流动性/历史门槛；股票宇宙加载单独缓存。
- 4只入围标的冷深度验证约30秒，确认深度分析而非本地评分是主要瓶颈，因此维持短名单上限和并发4。
- 相同4只规模在已有行情缓存下为1.75秒，说明检查点与行情缓存能显著降低重复运行耗时。
- A股与美股均保存逐标的检查点；同一交易日重启时跳过已完成标的。

## 未采用

- 对全市场逐只调用 `/api/analysis`：请求数过高，无法满足免费、稳定和可恢复的要求。
- 为缺失历史数据填入固定中性分：会污染排名，因此失败只披露、不参与入围。
