# 衡策 Quant Desk 新手语言词典

本词典约束新手主界面的用词。字段名、模型参数和专业模式保留准确术语；新手主文案先说结论、重要性和下一步，专业词只放在括号或次级说明中。

| 专业名词 | 页面主文案 | 次级专业名词 | 一句话解释 | 用户行动 |
| --- | --- | --- | --- | --- |
| VRVP | 历史成交密集区 | 可见范围成交量轮廓（VRVP） | 显示所选时间内哪些价位成交最多；这些位置常成为支撑或压力，但不是真实挂单墙。 | 等价格到密集区后观察能否站稳，不把单一点位当成保证。 |
| VWAP | 成交均价 | 成交量加权平均价（VWAP） | 把成交量考虑进去的平均价格，可判断现价离市场平均成本有多远。 | 偏离过大时不追价，等待回到计划区或出现新的确认。 |
| RSI | 价格强弱 | 相对强弱指标（RSI 14） | 近 14 根 K 线涨跌力量的比较；高位提示偏热，低位提示偏冷，但都不等于立即反转。 | 偏热先别追，偏冷等待止跌，再结合买入区行动。 |
| MACD | 趋势动量 | MACD（12,26,9） | 比较快慢趋势来观察上涨或下跌动力是否增强。 | 动力转弱时控制仓位；转强也要等价格确认。 |
| OHLCV | 日常行情数据 | 开高低收量（OHLCV） | 每根 K 线的开盘、最高、最低、收盘和成交量，是估算量价结构的基础，不是逐笔成交。 | 把估算结果当参考，不能当真实订单流或挂单墙。 |
| POC | 成交最密集价位 | 最大成交节点（POC） | 所选区间成交量最多的价位，价格回到这里时容易出现争夺。 | 观察能否站稳或受阻，再决定买、卖或继续等。 |
| Regime | 当前市场阶段 | 市场状态（Regime） | 把多项证据合成当前偏强、偏弱或修复等环境，不代表未来必然如此。 | 按阶段控制仓位上限，并持续检查失效条件。 |
| Impulse | 变化速度 | 脉冲/动量（Impulse） | 表示情绪或指标相对区间起点改善还是恶化。 | 改善仍要等价格确认；恶化时减少追高并等待企稳。 |
| 风险暴露 | 投入风险资产的资金比例 | 市场风险暴露 | 表示最多考虑把多少资金放在股票等风险资产，不是必须买满。 | 信心不足时取区间下限，其余资金保留现金。 |
| 回撤 | 从高点跌了多少 | 最大回撤 | 衡量最差阶段可能承受的下跌，帮助判断策略是否超出承受能力。 | 超过承受范围就减仓或放弃，不用收益掩盖风险。 |
| 流动性 | 是否容易成交 | 市场流动性 | 反映成交是否充足、买卖是否顺畅；不足时价格可能跳动且难按计划成交。 | 缩小仓位、放宽成交预期，避免在低成交标的中追价。 |
| 资金背离 | 价格在涨，但成交资金没有跟上 | 资金背离 | 上涨缺少成交支持，走势可能不稳。 | 暂不追高，等待成交跟上或价格回到计划区。 |
| 证据闸门 | 关键信息没核实前不生成买入计划 | 证据闸门 | 重要财务或行情证据缺失、冲突时阻止系统给出过度确定的建议。 | 先补齐或核对证据；闸门未通过时只观察。 |
| Client ID | 连接编号 | Client ID | 区分同一台电脑上的多个 IBKR 接口连接，不是账户或密码。 | 没有连接冲突就保留默认值；冲突时改成未占用编号。 |
| 数据覆盖率 | 可用关键信息比例 | 数据覆盖率 | 例如 30% 表示十项关键信息约只有三项可用，暂时不能形成可靠计划。 | 等待补齐或切换可靠来源，不把缺失项当成零分。 |
| 失效位 | 判断可能错了的价格 | 失效位 | 收盘跌破这个价格，说明原来的判断可能错了。 | 按计划减仓或退出，不用连续补仓代替止损纪律。 |
| 过期数据 | 数据不是最新的 | stale / 过期 | 旧数据可以说明历史情况，但不能代表当前市场。 | 查看截止时间，刷新成功前不据此新增仓位。 |
| 待补证 | 关键信息还没核实 | 待补证 | 系统知道缺什么，因此不会把缺失内容自动变成结论。 | 按提示补齐来源或等待更新，暂不形成买入计划。 |
| 不可用 | 现在不能可靠计算 | unavailable | 数据源、样本或权限不足，页面不会用虚构数字补位。 | 按页面提示重试、检查连接或改用可用来源。 |

## 文案检查规则

1. 标题、卡片标签和按钮先使用“页面主文案”；专业名词只能跟在括号或专业参数区。
2. 不删除“估算、最多、可能、等待确认、不构成单独依据”等风险限定语。
3. 错误、等待、不可用、过期和待补证状态必须同时给出当前影响和下一步。
4. 缺失数据不得显示为 0、0%、远离或买入。
5. ARIA 标签描述图表所表达的意思和键盘操作，不堆叠缩写。
