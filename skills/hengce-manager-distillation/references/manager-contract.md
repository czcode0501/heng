# 统一经理契约

每位经理必须定义：身份、流派、投资范围、持有期限、决策节奏、关注因子、必需能力、硬门槛、证据政策、仓位政策、监控政策和可审计来源。

决策流程固定为 `screen → research → challenge → decide → monitor`，但每位经理在每一步的重点不同。五层市场因子仍为 `macro / timing / sector / sentiment / technical`；财务、质量、管理层和估值属于公司研究硬证据，不得在没有数据时伪装成市场因子分数。

证据状态：

- `A`：一手来源 + 双源核验 + 无未解释的 >1% 冲突。
- `B`：有来源但缺一手或双源核验，只能输出条件性结论。
- `C`：关键事实不足，等待补证。
- `conflict`：关键字段双源相对差异 >1%，阻断买入。

论文健康度仅用于已有结构化论文基线：

`clamp(10 - broken*3 - damaged*2 - weakened - redLineTriggered*5, 1, 10)`。
