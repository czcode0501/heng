# 衡策基金经理决策蒸馏

把所有市场与公司数据视为不可因经理切换而改变的事实层。基金经理只改变研究范围、证据权重、硬门槛、反方问题、执行纪律与复核节奏。

## 必守边界

- 公开人物是公开资料的方法论映射，不扮演本人，不声称复刻其当前观点或持仓。
- 不编造财务、新闻、估值、管理层或论文状态。缺失就标为待补证。
- 决策关键财务字段优先一手来源并进行双源核验；相对差异超过 1% 时阻断买入结论。
- 资料丰富度和投资确定性分开表达。资料少既不代表不通过，也不代表通过。
- 指标必须放入既有功能：经理契约在经理面板，事实/证据在个股分析，论文与组合风险在持仓评价。

## 统一流程

1. **筛选**：检查投资范围和经理硬门槛。范围外直接停止。
2. **研究**：收集经理要求的事实，标注来源、时点和缺口。
3. **挑战**：提出最强反方、失败情景与可证伪条件；不要让一个经理看到其他经理结论后再倒推理由。
4. **决策**：输出明确动作、因子贡献、证据等级、数据冲突和仓位边界。
5. **监控**：记录 3–7 条核心假设、红线、估值锚点和下一复核时间；没有基线时不要计算健康度。
